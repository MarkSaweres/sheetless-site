  1. Click Copy signature. If that doesn't work, drag to select the signature above and press Ctrl+C.
  2. In your Namecheap webmail, open Settings, then Mail, then Signatures, and create a new signature.
  3. Click in the signature box and press Ctrl+V.
  4. Set it as the default for new messages and replies, then save.
